# game-char-blender-3d

Reconstruction of a cyberpunk female fighter from a four-view reference sheet into an editable 3D character (Blender).

- `reference/`: the original sheet and the per-view cut-outs (`reference/views/`)
- `scripts/`: pipeline scripts, numbered by stage
- `docs/`: stage reports and the quality inspection

Current status: see `docs/STAGE_01-03_REPORT.md`.
